# Lv 1. 평균 일일 대여 요금 구하기 (No. 151136)

[🔗 문제 바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/151136)

## 문제 설명

다음은 어느 자동차 대여 회사에서 대여중인 자동차들의 정보를 담은 `CAR_RENTAL_COMPANY_CAR` 테이블입니다. `CAR_RENTAL_COMPANY_CAR` 테이블은 아래와 같은 구조로 되어있으며, `CAR_ID`, `CAR_TYPE`, `DAILY_FEE`, `OPTIONS` 는 각각 자동차 ID, 자동차 종류, 일일 대여 요금 (원), 자동차 옵션 리스트를 나타냅니다.

| Column name | Type | Nullable |
|---|---|---|
| CAR_ID | INTEGER | FALSE |
| CAR_TYPE | VARCHAR (255) | FALSE |
| DAILY_FEE | INTEGER | FALSE |
| OPTIONS | VARCHAR (255) | FALSE |

자동차 종류는 '세단', 'SUV', '승합차', '트럭', '리무진' 이 있습니다. 자동차 옵션 리스트는 콤마 (',')로 구분된 키워드 리스트 (예: '열선시트', '스마트키', '주차감지센서')로 되어있으며, 키워드 종류는 '주차감지센서', '스마트키', '네비게이션', '통풍시트', '열선시트', '후방카메라', '가죽시트' 가 있습니다.

## 문제

`CAR_RENTAL_COMPANY_CAR` 테이블에서 자동차 종류가 'SUV'인 자동차들의 평균 일일 대여 요금을 출력하는 SQL문을 작성해주세요. 이때 평균 일일 대여 요금은 소수 첫 번째 자리에서 반올림하고, 컬럼명은 `AVERAGE_FEE` 로 지정해주세요.

## 예시

예를 들어 `CAR_RENTAL_COMPANY_CAR` 테이블이 다음과 같다면

| CAR_ID | CAR_TYPE | DAILY_FEE | OPTIONS |
|---|---|---|---|
| 1 | 세단 | 16000 | 가죽시트,열선시트,후방카메라 |
| 2 | SUV | 14000 | 스마트키,네비게이션,열선시트 |
| 3 | SUV | 22000 | 주차감지센서,후방카메라,가죽시트 |

'SUV' 에 해당하는 자동차들의 평균 일일 대여 요금은 18,000 원 이므로, 다음과 같은 결과가 나와야 합니다.

| AVERAGE_FEE |
|---|
| 18000 |

## 풀이

```sql
SELECT ROUND(AVG(DAILY_FEE), 0) AVERAGE_FEE
FROM CAR_RENTAL_COMPANY_CAR
WHERE CAR_TYPE = 'SUV';
```

- **반올림 관련 함수**

    | 기능 | 함수 | 설명 | 예시 | 결과 예시 |
    |---|---|---|---|---|
    | 반올림 | `ROUND(값, 자릿수)` | 지정한 자릿수까지 반올림 | `ROUND(123.456, 2)` | `123.46` |
    | 소수점 버림 | `TRUNCATE(값, 자릿수)` | 지정한 자릿수 아래를 버림 | `TRUNCATE(123.456, 2)` | `123.45` |
    | 올림 | `CEIL(값)` | 값보다 크거나 같은 가장 작은 정수 | `CEIL(123.1)` | `124` |
    | 올림 | `CEILING(값)` | `CEIL()`과 동일 | `CEILING(123.1)` | `124` |
    | 내림 | `FLOOR(값)` | 값보다 작거나 같은 가장 큰 정수 | `FLOOR(123.9)` | `123` |
    | 절댓값 | `ABS(값)` | 음수/양수를 절댓값으로 변환 | `ABS(-10)` | `10` |
    | 나머지 | `MOD(A, B)` | A를 B로 나눈 나머지 | `MOD(10, 3)` | `1` |
    | 거듭제곱 | `POWER(A, B)` | A의 B제곱 | `POWER(2, 3)` | `8` |
    | 제곱근 | `SQRT(값)` | 값의 제곱근 | `SQRT(16)` | `4` |

    - `ROUND` 자릿수 의미 및 결과

        | SQL | 의미 | 결과 |
        |---|---|---|
        | `ROUND(123.456, 2)` | 소수 셋째 자리에서 반올림 | `123.46` |
        | `ROUND(123.456, 1)` | 소수 둘째 자리에서 반올림 | `123.5` |
        | `ROUND(123.456, 0)` | 소수 첫째 자리에서 반올림 | `123` |
        | `ROUND(123.456)` | 자릿수 생략 → `ROUND(123.456, 0)`과 동일 | `123` |
        | `ROUND(125.456, -1)` | 일의 자리에서 반올림 | `130` |
        | `ROUND(125.456, -2)` | 십의 자리에서 반올림 | `100` |

- 집계 함수의 결과가 하나의 숫자 값이므로, 위 반올림 관련 함수와 함께 사용 가능
    - 집계 함수

        | 기능 | 함수 |
        |---|---|
        | 평균 | `AVG(컬럼)` |
        | 합계 | `SUM(컬럼)` |
        | 최대값 | `MAX(컬럼)` |
        | 최소값 | `MIN(컬럼)` |
        | 개수 | `COUNT(컬럼)` |

    - 예시:
        - `ROUND(AVG(DAILY_FEE), 0)`
        → 평균을 구한 뒤 소수 첫째 자리에서 반올림
        - `ROUND(SUM(PRICE), 2)`
        → 합계를 구한 뒤 소수 둘째 자리까지 반올림
