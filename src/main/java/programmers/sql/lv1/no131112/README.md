## 문제 설명

다음은 식품공장의 정보를 담은 `FOOD_FACTORY` 테이블입니다. `FOOD_FACTORY` 테이블은 다음과 같으며 `FACTORY_ID`, `FACTORY_NAME`, `ADDRESS`, `TLNO` 는 각각 공장 ID, 공장 이름, 주소, 전화번호를 의미합니다.

| Column name | Type | Nullable |
|---|---|---|
| FACTORY_ID | VARCHAR (10) | FALSE |
| FACTORY_NAME | VARCHAR (50) | FALSE |
| ADDRESS | VARCHAR (100) | FALSE |
| TLNO | VARCHAR (20) | TRUE |

## 문제

`FOOD_FACTORY` 테이블에서 강원도에 위치한 식품공장의 공장 ID, 공장 이름, 주소를 조회하는 SQL문을 작성해주세요. 이때 결과는 공장 ID를 기준으로 오름차순 정렬해주세요.

## 풀이

```sql
SELECT FACTORY_ID, 
       FACTORY_NAME, 
       ADDRESS 
FROM FOOD_FACTORY
WHERE ADDRESS LIKE '강원도%'
ORDER BY FACTORY_ID;
```
- `LIKE`: 문자열에서 특정 패턴과 일치하는 값을 조회 → `LIKE` 비교 패턴은 문자열이므로 작은 따옴표(`''`) 필수
- **와일드카드**
    - `%`: 0개 이상의 문자
    - `_`: 정확히 한 글자, 여러 개 사용 시 그 개수만큼 정확히 일치

    | 와일드카드 | 의미 | 예시 | 설명 |
    |---|---|---|---|
    | `%` | 0개 이상의 모든 문자 | `LIKE 'A%'` | `A`로 시작 |
    | `%` | 0개 이상의 모든 문자 | `LIKE '%A'` | `A`로 끝남 |
    | `%` | 0개 이상의 모든 문자 | `LIKE '%A%'` | `A`를 포함 |
    | `_` | 임의의 문자 정확히 1개 | `LIKE 'A_'` | `A` 뒤에 한 글자가 오는 문자열 |
    | `_` | 임의의 문자 정확히 1개 | `LIKE 'A__'` | `A` 뒤에 두 글자가 오는 문자열 |
    - `%`와 `_` 함께 사용 가능
        - 예: `LIKE 'A_%'`
            - 의미:
                1. `A`로 시작하고
                2. 그 뒤에 최소 한 글자가 반드시 있으며
                3. 그 이후에는 몇 글자가 더 와도 상관없음

## 다른 풀이

```sql
SELECT FACTORY_ID, FACTORY_NAME, ADDRESS 
FROM FOOD_FACTORY
WHERE LEFT(ADDRESS, 3) = '강원도'
ORDER BY FACTORY_ID;
```
- **문자열 자르기 함수**

    | 함수 | 의미 | 예시 |
    |---|---|---|
    | `LEFT(문자열, n)` | 왼쪽에서 n개의 문자 추출 | `LEFT(ADDRESS, 3)` → 처음 3글자 |
    | `RIGHT(문자열, n)` | 오른쪽에서 n개의 문자 추출 | `RIGHT(NAME, 2)` → 마지막 2글자 |
    | `SUBSTRING(문자열, 시작, 길이)` | 지정한 위치부터 원하는 길이만큼 추출 | `SUBSTRING(NAME, 2, 3)` → 2번째 문자부터 3글자 |
    | `SUBSTR(문자열, 시작, 길이)` | `SUBSTRING()`과 동일 | `SUBSTR(NAME, 2, 3)` → 2번째 문자부터 3글자 |
